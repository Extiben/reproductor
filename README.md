# KTOmusic 2.0

Reproductor de escritorio con búsqueda de metadata en Spotify, caché local JSON y descarga opcional mediante yt-dlp.

## Inicio rápido

1. Activa el entorno: `venv\Scripts\Activate.ps1`.
2. Copia `.env.example` como `.env` y completa las credenciales de Spotify.
3. Ejecuta `python main.py`.

La ventana y el caché funcionan sin FFmpeg. Instálalo antes de activar la descarga y conversión a MP3.
